# Autonomous Vehicle Course

Coursework for **Software Development for Intelligent Autonomous Vehicles** (67006),
Holon Institute of Technology (HIT), semester A, 2026–2027.

## About

The course covers the software stack of an autonomous vehicle: middleware (ROS 2, DDS),
perception (LiDAR, camera, radar), localization, motion planning and control, and HD maps.
